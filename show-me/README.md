# "Show me" modules

Playable, game-style practice modules. Each one puts safety first (hazards and the hierarchy of
controls), then asks the trainee to plan, forecast the next steps, ask questions, diagnose, fix and close out.

| Module | Level | File |
|---|---|---|
| Flashing pole light (exterior LED area light) | LT3 | `flashing-pole-light.html` |

Example figures in the modules (costs, wind limits, the repair-or-replace threshold) are training data and
need subject-expert review before launch.
