# Discussion 004: What to do with the archived electrical courses

## Background
The program now ends at **Senior (LT4)** and **Master Lighting Technician (LT5)**. It no longer
leads to a journeyman electrician license, because that requires an accredited school or
state-approved apprenticeship.

The draft electrical-apprentice levels were **not deleted**. They are archived in
`curriculum/archive/electrical-track/`, and you can read every lesson in the review site under
**"Archived: Electrical Development courses."**

| | Courses | Lessons | Quiz questions | Hands-on skills |
|---|---|---|---|---|
| Archived (EA1–EA4, JW) | 24 | 95 | 408 | 37 |

One course has already moved back into the program: **EA3-C05 NFPA 70E & Qualified Worker Safety**
is now **LT4-C07**. It holds the company energized-work rules and permit.

The question: should any of the rest come back, reworded as Senior or Master Lighting Technician
topics instead of apprentice and journeyman topics?

## What each archived course contains, and my take

**Ratings:**
- **Bring back:** useful for senior and master lighting techs. Reword and add.
- **Partial:** a few lessons are worth folding into existing courses.
- **Leave archived:** licensed-electrician or exam-only content.

## Options

| Option | What it means | Effort |
|---|---|---|
| A. Leave everything archived | Nothing changes; the content stays available for later | None |
| B. Fold "Partial" lessons into existing courses | Add selected lessons to LT2–LT5 courses where they fit | Medium |
| C. **Senior Electrical Knowledge elective** | A separate, optional module, like the Manager Module, for LT4 and LT5 techs, built from the "Bring back" courses reworded as senior lighting topics. It is not required for promotion. Hands-on skills become "inspect, recognize and escalate" rather than "install," so they stay within lighting-tech scope. | Medium to large |
| D. Restore the old track as-is | Not recommended: it promises a path the program doesn't offer | n/a |

## My recommendation
Do **B + C**:
- Fold the quick wins into existing courses: code lookup → LT4-C06, GFCI/AFCI → LT1-C09,
  building automation → LT4-C01, Class 2 circuits → LT3-C03.
- Build an optional **Senior Electrical Knowledge** elective from seven courses: construction
  safety, AC theory, grounding and bonding, blueprint reading, three-phase distribution, special
  occupancies, and renewables/storage/EV. Reword each for senior lighting techs, with a clear note
  that installation work reserved for licensed electricians stays with them.
- Leave conduit bending, motors, services, load calcs and exam prep archived.

This keeps the best of the material, adds depth for senior and master techs, and stays inside what
the program promises.
