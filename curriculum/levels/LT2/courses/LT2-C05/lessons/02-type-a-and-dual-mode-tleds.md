## How Type A Works

A **Type A** TLED contains circuitry designed to accept the high-frequency output of an
electronic fluorescent ballast. You remove the fluorescent lamp, insert the TLED, and the
existing ballast powers it. No rewiring, no fixture modification, no retrofit labels
required by the lamp (follow the lamp's instructions).

## Advantages and Limitations

| Advantages | Limitations |
|---|---|
| Fastest installation — no wiring | Works only with **compatible** ballasts |
| No line voltage at sockets — relamping risk unchanged | The ballast still fails eventually — and then the TLED goes dark too |
| No fixture modification or labels | Ballast losses reduce efficiency compared with Type B or C |
| Easy to revert to fluorescent | Light output and power depend on ballast factor |
| | Compatibility issues can cause flicker, buzzing, short life, or overheating of the ballast or lamp |

## Compatibility Is Everything

Type A tubes are tested with specific ballasts. Before installing:
1. **Read the ballast label** — manufacturer, model, starting method, ballast factor.
2. **Check the TLED manufacturer's compatibility list** (usually online). Look for the exact
   ballast model, not just the brand.
3. **Watch for ballast type restrictions.** Many Type A tubes are listed for instant-start
   electronic ballasts; fewer for programmed or rapid start. **Most are not compatible with
   magnetic ballasts** — magnetic T12 systems are generally not Type A candidates.
4. **Check the ballast's age and condition.** If the ballast is near end of life, the
   customer will pay for a service call soon anyway. Discuss Type B or C instead.

If a ballast is not on the list, don't "try it and see." Incompatible combinations may work
for a while and then fail, overheat, or flicker.

## Installing Type A Tubes

1. **Plan.** Confirm compatibility for every fixture type in the job. Fixtures that look
   the same may have different ballasts.
2. **Lock out or follow the company relamping procedure** (LT1-C06). Many companies require
   lockout for all relamping in 277 V fixtures.
3. **Remove fluorescent lamps** and manage them as universal waste.
4. **Inspect sockets.** Replace cracked, loose or heat-damaged sockets with the same type
   (shunted for instant-start ballasts; non-shunted for RS/PS) as the existing ballast
   requires.
5. **Install TLEDs**, seating pins fully and rotating to lock (for bi-pin G13). Observe any
   orientation marks.
6. **Restore power and verify** — all tubes light, no flicker, no buzzing, and fixture
   responds to its normal control.
7. **Document** the ballast model and TLED model by location — this makes future service
   easier.

## Troubleshooting Type A

| Symptom | Likely cause |
|---|---|
| Tube dark, others on same ballast lit (parallel IS) | Failed tube, poor socket contact, or that ballast output failed |
| All tubes on a ballast dark | Ballast failed (most common), supply/control issue, or tubes incompatible |
| Flicker or strobing | Incompatible ballast, failing ballast, or dimming ballast not supported |
| Tube end hot, discolored socket | Poor contact, incompatible ballast, or damaged socket |

A failed ballast in a Type A installation is a decision point: replace the ballast with a
compatible model, or convert the fixture (Type B or C) with the customer's approval.

## Dual-Mode (Hybrid) Tubes

**Dual-mode** tubes (sometimes called Type A/B) operate on a compatible ballast **or** directly
on line voltage after the ballast is bypassed. Their selling point: install today as Type A,
and when the ballast fails, convert instead of buying a new ballast.

Key points:
- **When the ballast fails, the conversion is a Type B conversion.** Follow the tube
  manufacturer's bypass wiring diagram exactly (single-ended or double-ended), check socket
  type, and **apply the line-voltage and modification labels**. The next lesson covers the
  procedure.
- **Never leave a fixture partly converted.** All lamp positions on a fixture should be
  wired the same way.
- **Document** which fixtures have been converted so the customer and future techs know.
- **Read the instructions carefully** — some dual-mode products have specific wiring
  requirements in bypass mode that differ from a dedicated Type B.

> **Safety:** A fixture that was installed as Type A and later bypassed now has line voltage
> at its sockets. If it is not labeled, the next person relamping it will assume ballast
> output and may handle sockets energized. Labels are not optional.

## Where Type A Is a Poor Choice

- Magnetic ballasts, or ballasts not on the compatibility list
- Ballasts that are old or already failing
- Fixtures controlled by dimming ballasts (unless the tube and ballast are specifically
  listed together for dimming)
- Very cold or very hot environments outside the tube's rating
- Fixtures with fluorescent emergency ballasts — compatibility with TLEDs must be confirmed;
  usually a different emergency solution is needed (LT3-C04)

## Key Takeaways
- Type A TLEDs run on the existing fluorescent ballast — no wiring, no fixture modification.
- Compatibility with the exact ballast model is essential; most Type A tubes are not for magnetic ballasts.
- The ballast remains a failure point and reduces system efficiency.
- Dual-mode tubes can be bypassed later — that bypass is a Type B conversion and requires labels.
- Never leave fixtures partly converted, and document what was installed where.
