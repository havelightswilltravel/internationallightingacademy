## Why Retrofits Need Care

LED retrofits are now a large share of lighting service work. A retrofit changes how a
fixture was originally listed to operate. Done correctly, it is safe, efficient and
code-compliant. Done carelessly, it can leave **line voltage on lamp sockets** with no
warning, void the fixture's safety listing, or create a fire hazard. This course gives you
the knowledge to do retrofits right; LT3-C01 covers LED technology and drivers in depth.

## The Main Options

| Option | What it is | Fixture modified? |
|---|---|---|
| UL Type A TLED ("plug and play") | LED tube that runs on the existing fluorescent ballast | No |
| UL Type B TLED ("ballast bypass" / "direct wire") | LED tube with internal driver; ballast removed and sockets wired to line voltage | **Yes** |
| UL Type C TLED ("remote driver") | LED tubes powered by a separate external LED driver that replaces the ballast; low voltage to the sockets | **Yes** |
| Dual-mode / hybrid (often called Type A/B) | Works on a compatible ballast and can later be converted to ballast bypass | No at first; **yes** after bypass |
| Retrofit kit (troffer, strip, high-bay) | LED panels, strips or modules with driver that install into an existing housing | **Yes** |
| LED replacement lamps for screw bases (medium or mogul) | LED lamps replacing incandescent, CFL or HID lamps; HID types may run on the ballast or require bypass | Depends on type |

## The Standards Behind the Labels

You do not need to memorize standards, but you need to recognize them on packaging.

| Standard | Covers |
|---|---|
| UL 1993 | Self-ballasted lamps and lamp adapters — includes LED lamps and many TLEDs |
| UL 1598C | LED retrofit kits for luminaires — kits that modify an existing fixture (Type B and Type C kits, troffer kits) |
| UL 8750 | LED equipment for use in lighting products (drivers and LED modules) |
| UL 1598 | Luminaires (the original fixture's standard) |

### Why the NEC cares

The NEC requires luminaires, lampholders and **retrofit kits** to be listed (Article 410),
and requires listed equipment to be installed per its instructions (110.3(B)). Retrofit kits
evaluated to UL 1598C come with **instructions that define exactly which fixtures they may
be installed in and how**, plus **labels that must be applied**. If you don't follow the
instructions and apply the labels, the installation is not compliant, even if it works.

Some retrofit kits are "UL Classified" for installation into specific types of listed
luminaires rather than "Listed" as complete products. Either way, the kit's instructions and
labeling are what make the modified fixture acceptable. If a kit has no recognized
certification mark, **do not install it** — tell your lead.

## Required Labels

Retrofit kits that modify a fixture include labels to be applied at installation. Typical
label content (exact wording comes from the kit):
- The luminaire **has been modified** and can **no longer use the original lamps**
  (e.g., do not install fluorescent lamps).
- For ballast-bypass (Type B): a warning that **line voltage is present at the lampholders**
  (risk of shock).
- Identification of the retrofit kit (manufacturer, model) and, on some kits, space for the
  installer/date.

Labels go where the instructions say — commonly on the fixture near the lampholders and on
the outside of the fixture where they are **visible during relamping**. A missing label is
one of the most common retrofit deficiencies inspectors and customers find.

> **Safety:** The label protects the next person who works on that fixture. A tech who
> assumes "it's fluorescent" and handles sockets with power on can be shocked at full
> 120 V or 277 V. Always apply every label supplied with the kit, and treat any fixture
> you open as possibly converted until you verify otherwise.

## DLC and Utility Incentives

The **DesignLights Consortium (DLC)** maintains a Qualified Products List of LED products
that meet performance criteria (efficacy, lumen maintenance, warranty). Many utility rebate
programs require DLC-qualified products. When a customer is participating in a rebate
program, install **exactly** the approved model — substitutions can cost the customer the
incentive. LT4-C02 covers energy codes and incentives.

## Choosing an Option — First Pass

| Question | Points toward |
|---|---|
| Customer wants the fastest, lowest labor install and ballasts are relatively new and compatible | Type A |
| Ballasts are old, failing or incompatible; customer wants lowest long-term maintenance | Type B (or Type C) |
| Dimming or controls required, best efficiency, or highest-quality result | Type C or a full retrofit kit |
| Fixture housings are in poor condition (rusted, broken sockets, yellowed lenses) | Retrofit kit or new fixture rather than tubes |
| Emergency battery ballast present | Requires a compatible LED emergency solution (LT3-C04) — plan before converting |

## Key Takeaways
- Retrofit options: Type A, Type B, Type C, dual-mode, retrofit kits, and screw-base LED replacement lamps.
- Type B, Type C and retrofit kits modify the fixture; follow the kit's instructions exactly (NEC 110.3(B)).
- UL 1993 covers lamps; UL 1598C covers retrofit kits; the NEC requires retrofit kits to be listed.
- Apply every label supplied with the kit, where the instructions say — especially line-voltage-at-lampholder warnings.
- Install exactly the specified DLC-qualified model when a rebate is involved.
