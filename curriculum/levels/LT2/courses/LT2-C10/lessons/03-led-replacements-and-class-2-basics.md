## Why LED MR16 Swaps Cause Callbacks

Customers love replacing a 50 W halogen MR16 with a 6–8 W LED MR16. Many swaps work perfectly.
Many do not, because the **transformer was designed for halogen**.

| Problem | Why it happens |
|---|---|
| Flicker or strobing | Electronic transformer's output or control loop does not play well with the LED lamp's internal electronics |
| Lamps will not start or cycle on/off | Total LED load is **below the transformer's minimum load** |
| Lamps flash at low dim levels or will not dim | Dimmer/transformer/lamp combination not compatible |
| Buzzing | Dimmer or transformer interaction |
| Early LED lamp failure | Heat in enclosed fixtures, overvoltage from a magnetic transformer on a high tap with very light load |
| Some lamps work, some don't on the same transformer | Mixed lamp brands, marginal compatibility |

### Magnetic transformers with LED lamps

Magnetic transformers are generally more tolerant of LED lamps, but very light loads can cause the
output voltage to **rise** above 12 V. Check the LED lamp's input range.

### Electronic transformers with LED lamps

This is where most problems occur. Check:

1. The transformer's **minimum load** vs the total LED wattage.
2. The LED lamp maker's **compatibility list** (most publish lists of tested transformers and
   dimmers).
3. Whether the transformer is marked as LED compatible.

## Fixing an LED MR16 Compatibility Problem

1. **Confirm the symptom** and which lamps are affected.
2. **Identify the transformer**: integral or remote, magnetic or electronic, VA, min/max load,
   dimming type.
3. **Total the LED load** and compare with the minimum load.
4. **Check the lamp maker's compatibility list** for that transformer and any dimmer.
5. Choose a fix:
   - Use a lamp that is listed as compatible with the existing transformer, or
   - Replace the transformer with an **LED-compatible** unit (or an LED driver approved for that
     fixture), sized to the new load — this is a transformer replacement on line-voltage primary
     connections, done after lockout and verification, or
   - Replace the fixture with an integrated LED fixture.
6. If dimmed, confirm the **dimmer** is on the compatibility list too.
7. Test at full output and across the dimming range.

> **Safety:** Replacing a transformer means working on its **line-voltage primary**. Lock out and
> tag out the circuit, verify absence of voltage with a tested meter (live-dead-live), and make
> sure the replacement is listed for use in that fixture or location. Modifying a listed fixture
> with a non-approved component may void its listing — use the maker's part or a retrofit kit
> listed for the purpose.

## Class 2 Basics

Many low-voltage lighting systems — landscape lighting, cable systems, under-cabinet LED and some
display lighting — use **Class 2** power sources. A Class 2 power source limits the voltage and
power available on its output so that the circuit presents a low fire and shock risk. Typical Class
2 transformers for lighting are limited to about 100 VA per output.

What that means for you in the field:

| Topic | Field meaning |
|---|---|
| Marking | The transformer/power supply is labeled "Class 2." Only a listed Class 2 source makes the circuit Class 2 |
| Wiring | Class 2 output wiring may use different wiring methods than line-voltage wiring (for example, low-voltage landscape cable), within the product listing and code rules |
| Separation | Class 2 conductors must be kept separate from line-voltage conductors (not in the same raceway, box or compartment unless separated by a barrier or as the code permits) |
| Multiple outputs | A large landscape transformer may have several Class 2 outputs, each individually limited |
| Not Class 2 | A 600 VA transformer with a single 12 V output is **not** Class 2 — its secondary carries enough energy to start fires and must be wired accordingly |

> **Safety:** The primary side of a Class 2 transformer is still a line-voltage circuit. "Low
> voltage" describes the output only.

Code note: Class 2 circuits are covered in NEC Article 725 in the 2023 edition (article numbering has
changed between editions — use the AHJ-adopted edition). Low-voltage lighting systems are addressed in NEC Article 411. Check
with an electrician or the AHJ for specific wiring-method questions.

## Parts Identification and Ordering

When replacing low-voltage lamps, transformers or fixtures, record:

| Item | Record |
|---|---|
| Lamp | Shape (MR16, MR11, PAR36), base (GU5.3, GU4, G4, GY6.35), voltage (12/24 V), wattage, beam angle, CCT, CRI, open/enclosed rating, halogen or LED |
| Transformer | Input voltage, output voltage, VA, magnetic or electronic, min/max load, dimming type, Class 2 yes/no, integral or remote, dimensions/mounting |
| Fixture | Manufacturer, catalog number, transformer part number from the label |
| Dimmer | Type (MLV/ELV/LED), rating in VA/W, compatibility list reference |

## Key Takeaways
- LED MR16 problems usually come from transformer compatibility: minimum load, flicker and dimming.
- Check the lamp maker's compatibility list and the transformer's minimum load before ordering LED replacements.
- Fixes: a compatible lamp, an LED-compatible transformer or driver, or a new integrated LED fixture.
- Class 2 sources limit output energy; only a listed Class 2 source makes a circuit Class 2, and its primary is still line voltage.
- Record lamp base, beam, wattage and transformer type, VA, min/max load and dimming when ordering.
