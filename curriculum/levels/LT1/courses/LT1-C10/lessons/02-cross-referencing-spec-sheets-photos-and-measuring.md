## Cross-Referencing Between Manufacturers

Most lamps, ballasts and many drivers are made by several manufacturers. A
**cross-reference** finds an equivalent part from a different brand, usually because the
supply house stocks a different brand than the one in the fixture.

**Sources for cross-references:**

- Manufacturer cross-reference tools on their websites and apps (search by competitor part number)
- The supply house counter staff, who use the same tools and catalogs every day
- Manufacturer representatives (Lesson 3)

### What must match on a cross

A cross-reference tool is a starting point, not the final answer. Before you accept a
crossed part, compare the label fields yourself:

| Part | Fields that must match |
|------|------------------------|
| Fluorescent lamp | Wattage, diameter, length, base, color temperature, CRI; ballast compatibility for reduced-wattage lamps |
| Fluorescent ballast | Lamp type and quantity, start method, input voltage, ballast factor, case size and mounting, dimming if any |
| HID lamp | Wattage, ANSI code, probe vs pulse start, burn position, bulb shape and base, enclosed/open rating |
| HID ballast | ANSI code, input voltage (single, multi-tap, or quad), core-and-coil or kit form, capacitor and ignitor specs |
| LED driver | Input voltage, CC vs CV, output current, output voltage window, power, dimming type, case size, mounting holes |
| Socket | Base type, mounting style, shunted vs non-shunted (fluorescent), wire lead length, temperature rating |

If even one field does not match, ask before ordering. **Never cross an LED driver by
wattage alone.** A 40 W, 1050 mA driver will destroy a board designed for 700 mA.

## Spec Sheets and Installation Instructions

Every manufactured product has a **specification sheet** (dimensions, ratings, options,
ordering logic) and **installation instructions** (wiring, mounting, warnings).

How to get them:

1. Search the manufacturer's website by the full catalog number or part number.
2. Scan the QR code on the label or box, if there is one.
3. Ask the supply house or the manufacturer rep to send them.
4. Save them to the work order or the company's document folder for that customer so the
   next tech has them.

Read the installation instructions **before** installing a crossed or unfamiliar part.
Wiring colors and connection methods differ between brands, especially for LED drivers and
retrofit kits.

## Photographing Labels

A good label photo can save a trip. Before you remove a part, and after you lock out:

1. **Take a wide shot** first, showing the fixture and its location or tag number.
2. **Photograph the whole label**, square to the camera, filling the frame.
3. **Control glare.** Tilt the phone slightly or shade the label with your hand; turn off the
   flash if it washes out shiny labels.
4. **Tap to focus** and check the photo by zooming in before you move on. Every character
   must be readable.
5. **Include the wiring diagram** on ballast and driver labels.
6. **Add a tape measure** for scale when photographing lenses, lamps, or sockets.
7. **Photograph the inside**: sockets, the driver/ballast location, mounting holes and wiring.

If a label is faded, photograph it anyway at several angles. Sometimes the text shows up in
one shot.

## Measuring

When a label is missing or unreadable, measurements identify the part.

| Item | Measure | Tips |
|------|---------|------|
| Linear lamp | Overall length including pins, and diameter | 4 ft T8 is 48 in; 4 ft T5 is about 46 in |
| Screw-base lamp | Base diameter (E12/E17/E26/E39), overall length, max diameter | A base gauge makes this easy |
| Pin-base lamp | Pin spacing and pin shape | Compare to a base chart |
| Lens or diffuser | Length x width x thickness, pattern (prismatic, frosted, louver), material (acrylic or polycarbonate) | Measure the lens, not the door frame; note how it attaches |
| Ballast or driver | Case length, width, height, and mounting-hole spacing | Retrofitting a different case size may need new holes or a mounting kit |
| Recessed can | Aperture diameter (4, 5, 6 in), housing depth | Needed for retrofit modules |
| Socket | Mounting style, spacing between sockets | Shunted vs non-shunted is not visible; check the marking or test |

> **Safety:** Measure fixtures with the circuit locked out and verified dead. Lamps and
> drivers can be hot, and a hand inside an open fixture is close to energized parts.

## Key Takeaways
- Cross-reference tools are a starting point; compare every critical field yourself.
- Never cross an LED driver by wattage alone; output current and voltage window must match.
- Get the spec sheet and installation instructions from the catalog number and save them to the job.
- Photograph labels square, in focus, without glare, with a wide shot and a scale reference.
- Measure lamps, bases, lenses, cases and cans when labels are missing.
